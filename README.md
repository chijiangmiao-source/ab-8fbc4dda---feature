# 超导磁通探针整数相位面复核与有向复测闭环规划

从带整周跳变的有向边差观测中，**精确**复原一张可用于补偿的整数相位面；
取得相位面后，还可勾选需要重新测量的可疑观测边，**精确**规划一条从指定
探针出发并返回的最短有向复测闭环。所有重计算在浏览器内的 Web Worker 中
完成，页面本身是零运行时依赖的纯静态应用。

## 解决的问题

- 探针编号 `0 … n-1`（2 ≤ n ≤ 40），其中一个**参考探针固定相位为 0**；
- 每个探针有整数相位范围 `[lo_i, hi_i]`；
- 有向观测边 `u → v` 给出目标差值 `t_e` 与正整数权重 `w_e`；
- 在**所有**范围内整数赋值中最小化

      Σ_e w_e · | (x_v − x_u) − t_e |

- 总成本相同时，取按探针标识升序的相位向量 `(x_0, x_1, …)` **字典序最小**者。

不沿生成树逐边累加（闭环矛盾时局部传播不是最优），不使用浮点，也不枚举全赋值。

## 算法：凸整数标签 → 最小割（一次最大流）

有序整数标签的凸代价可归约为 s-t 最小割（Ishikawa 链式图）：

- 二值变量 `z_{i,k} = [x_i ≥ k]`，节点 `(i,k)` 在源侧 ⇔ `z=1`；
- 链内 `+∞` 弧 `(i,k+1) → (i,k)` 强制截集是一个阈值；
- 成对项 `w·|x_v − x_u − t|` 的受限二阶差分仅当 `l − k = t` 时为 `2w`，
  对应弧 `(u,k) → (v,l)`；有限定义域边界的一阶项用源/汇弧精确补偿；
- 参考探针用 `+∞` 钉死弧固定为 0；
- 整数容量 Dinic（显式栈迭代实现，宽范围不栈溢出）求最大流；
- 最大流后从源点沿残量弧可达的集合是**唯一的最小最小割**，
  它在所有最优割中逐分量最小，因而解码出的正是字典序最小的最优解——无需多轮求解。

总代价与每条边的实际差/残差/贡献在求解后按定义用整数复算，并与网络值交叉核对。

## 有向复测闭环规划（可疑边巡检）

相位面出来之后，校准员可在边表勾选**至多 24 条**需要重新测量的观测边并指定
**出发探针**，生成一条回到出发点的**最短有向闭环**——规划只能沿当前录入的
有向观测边前进（其他边可作过渡），被勾选边至少经过一次，一次巡检覆盖所有
可疑边，无需分别安排往返。

### 算法：最短路 → 整数最小费用平衡 → 欧拉展开（三步，无浮点）

1. **有向最短过渡路**：以“边数”为整数距离，从每个探针做 BFS，得到所有
   探针间的最短距离与按录入顺序确定的唯一前驱；可疑边端点从出发探针不可达、
   或走完可疑边后回不到出发点时，明确报告“从何探针不能到达何处”并清除旧路线。
2. **整数最小费用平衡**：把每条可疑边计一次必现度数 `b[v]=出−入`；`b>0`
   接汇（需求）、`b<0` 接源（供应），供应→需求间加费用为最短边数、容量取整数
   上界的过渡弧，用 Bellman-Ford 逐次最短路增广求整数最小费用流（残量反向弧
   为负费用，不能用 Dijkstra 或浮点势）——**不是逐边贪心、不枚举路线**。
3. **欧拉展开**：平衡流每单位流沿第 1 步的最短路边序展开为过渡边，与可疑边
   合并为平衡多重图；若可疑边自身构成与出发地断开的平衡小环，用整数子集 DP
   求一条同时访问各断开分量的最短访问步行再展开。最后由 Hierholzer（迭代栈）
   展开一条从出发探针回到出发探针的有向闭环，输出完整边序、每步起止探针及
   每条可疑边的首次到达位置。

### 反贪心验收样例（页面“载入单向绕行复测样例”按钮）

5 个探针、12 条有向边，勾选 `0→3`、`1→0`、`2→3`，从探针 0 出发：

- 最近边优先（距离并列取序号小者）：`0→3→1→0→…→2→3→…→0`，共 **7** 步；
- 本规划器：`0→3→2→3→1→0`，共 **5** 步，三条可疑边首次到达位置依次为
  第 1、3、5 步。

输出同时给出每条可疑边的首次到达步号、完整边序（标注可疑边首次/重复/过渡）、
闭环总长度以及平衡/拼回的过渡边步数明细。

## 浏览器中的并发生命周期

- 最小割运行在 [Web Worker](src/worker/solver.worker.js) 中，异步扫描会周期性让出事件循环；
- 每次复核带一个**代际令牌**；草稿修改、发起新复核或点击取消都会作废旧令牌，
  旧计算在下一个让出点停止且其结果永不回传，主线程也只接受当前代际的消息——
  旧计算不可能覆盖当前界面状态；
- 复测闭环规划在**独立的第二个 Worker** 中运行，使用同一套代际令牌机制：
  修改勾选或出发探针只作废旧路线（相位面结论保留）；修改草稿（探针/边）会
  同时作废两条链的令牌，旧路线与旧相位面结论都不能回屏；清除路线按钮与
  不可达结论同样先清空旧路线，再给出当前诊断；
- 校验失败（范围为空、参考点 0 越界、边端点不存在、权重非正整数等）会
  在页面上定位到具体探针行/边字段，并清除旧结论。

## 本地开发

```bash
npm install
npm test       # node --test：含 400 组相位面对暴力枚举的对照、
               # 闭环规划对记忆化精确最优步行的随机对照与反贪心验收、
               # 20 万阈值层宽范围、两个 Worker 的代际取消端到端测试等
npm run dev    # 开发服务器
npm run build  # 产出纯静态文件 dist/
```

## Docker Compose

`compose.yaml` 提供两个服务：

```bash
# 页面（静态应用），宿主机端口默认 8080，可用 WEB_PORT 覆盖：
docker compose up web
#   浏览器打开 http://localhost:8080
WEB_PORT=9000 docker compose up web

# 一次性复核容器：代码测试 → 构建检查 → HTTP 冒烟，完成后自行退出，
# 容器退出码即复核结果（0 成功，非 0 失败）：
docker compose up --build verify
```

- `web`：多阶段构建，`vite build` 产物由 nginx 提供；
  容器健康检查直接抓取首页并核对应用标记（静态应用可用才健康）。
- `verify`：等待 `web` 健康后运行 [scripts/verify.sh](scripts/verify.sh)——
  `npm test`、`npm run build`（并核对 Worker bundle 已产出）、
  对首页/JS/CSS/Worker 资源/`/healthz` 做 HTTP 冒烟，任一失败即以非零码退出。

## 内置样例

页面载入时默认填充“闭环矛盾三角形”：

| 边 | 目标差 | 权重 |
|---|---|---|
| 0→1 | 1 | 10 |
| 0→2 | 1 | 1 |
| 1→2 | 1 | 10 |

按录入顺序选生成树 `{0→1, 0→2}` 逐边累加得 `(0,1,1)`，高权闭合边 `1→2`
残差 −1，代价 10；精确最小割最优解为 `(0,1,2)`，只有低权弦残差 1，代价 **1**。
另提供一个四环“局部累加失败”样例与一个“单向绕行复测”样例（按钮载入，
后者用于验收闭环长度 5 对最近边优先 7 的反贪心性）。
